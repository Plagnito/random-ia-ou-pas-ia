# IA ou pas IA ?

Pres de quatre cents duels, autant de paires d'images. La moitie est generee,
l'autre est photographiee. Deux facons de jouer : **duel** (les deux images du meme sujet,
cote a cote) et **solo** (une image seule, sans point de comparaison).

Deux niveaux, choisis sur l'ecran d'accueil :

- **standard** — cent sujets ordinaires (un renard, un bol de ramen, un phare) ;
- **expert** — trois cents sujets choisis pour n'offrir AUCUNE prise a l'oeil :
  matiere et texture, gros plans, interieurs banals, lumiere difficile, vues
  aeriennes. Ni visages, ni texte, ni monument reconnaissable — c'est-a-dire
  aucun des indices sur lesquels on repond d'habitude sans regarder l'image.

- Les images generees viennent de **Z-Image Turbo**, execute en local, sans
  retouche. Huit etapes pour le lot standard, **seize** pour le lot expert : a
  huit etapes les surfaces sortent trop lisses, et ce lissage est justement ce
  que l'oeil apprend a reconnaitre.
- Les photographies viennent de **Wikimedia Commons**, toutes sous licence
  libre. L'auteur et la licence de chacune s'affichent a la revelation.

**L'ordre est tire au sort a chaque partie** : celui des sujets, et le cote de
l'image generee en mode duel. Pour rejouer exactement la meme partie — utile a
un animateur qui a repete son commentaire — ajouter `?graine=1234` a l'adresse.

Le jeu fonctionne aussi hors ligne : ouvrir `index.html` suffit.

## Licences

Les images generees sont produites pour ce jeu. Les photographies restent sous
**leur propre licence** (CC BY, CC BY-SA, CC0, domaine public) : l'auteur, la
licence et le lien vers la page Commons de chacune sont donnes dans la page
**Credits et licences** du jeu (touche `C`, ou le lien sur l'ecran d'accueil).
Les copies utilisees ici sont legerement recadrees, redimensionnees et
converties en AVIF, et sont redistribuees aux memes conditions que l'original.

## Clavier

| Touche | Effet |
|---|---|
| `1` / `A` / `I` | repondre : A, ou « generee par IA » |
| `2` / `B` / `P` | repondre : B, ou « vraie photo » |
| `Espace` | reveler sans repondre, puis image suivante |
| `<-` | revenir en arriere |
| `R` | basculer la revelation |
| `G` | grille de toutes les images |
| `C` | credits et licences |
| `F` | plein ecran |

`Espace` sans repondre existe pour l'animation en direct : le public vote a
l'oral, l'animateur revele sans fausser le score.
